## Source Eligibility Checklist
- Crawlable and returns an expected response
- Indexable and canonicalized correctly
- Main content visible in rendered output
- Clear first-answer section when appropriate
- Clear entity relationships
- Claims supported by evidence
- Useful internal links and topic support
- Structured data matches visible content
- Freshness is meaningful, not cosmetic
- Extraction controls are intentional

Unchecked items are `NOT TESTED`.
