# Release Notes: SEO Master System v7.3 Editorial Humanization Governance

## Release objective
Correct Module 09 so the system performs direct editorial and batch-similarity audits itself. External AI-detector results are optional supporting inputs, never prerequisites or verdict controls.

## Major corrections

1. Replaced detector-first Mode A with direct Single-Asset Editorial Humanization Audit.
2. Reframed batch review as Batch Humanization and Similarity Audit for two or more related assets when material risk exists.
3. Moved detector handling into optional External Detector Result Governance.
4. Added Combined Audit mode and explicit mode-selection priority.
5. Prohibited requiring or simulating detector tests.
6. Updated controllers, README files, START_HERE files, manuals, manifests, changelogs, migration notes, and validation records across Full/Lite and flat/nested variants.
7. Preserved controller authority for severity and final verdict.

## Team expectation
The system must provide the strongest evidence-based recommendation available, correct weak premises when necessary, and distinguish direct inspection, calculated findings, supplied evidence, inference, and untested claims.
