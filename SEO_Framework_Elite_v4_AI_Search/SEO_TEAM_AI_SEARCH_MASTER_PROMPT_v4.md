# SEO Team Master Prompt v4 — SEO + AEO + GEO + AI Search Visibility

## Purpose

Use this prompt to plan, brief, create, refresh, and audit content for modern search visibility across:

- Google Search
- Google AI Overviews
- Google AI Mode
- Bing / Copilot
- ChatGPT Search
- Perplexity-style answer engines
- Gemini-style answer systems
- Other generative search and citation systems

The goal is not only to rank. The goal is to make the page crawlable, indexable, understandable, extractable, cite-worthy, and useful enough for a human buyer to trust.

Do not create generic SEO content. Do not write keyword-stuffed copy. Do not invent proof. Build content around search intent, entities, evidence, technical accessibility, and answer quality.

## 2. Search Environment Objective

Optimize the page for four visibility layers.

| Layer | Main Goal | Optimization Focus |
|---|---|---|
| SEO | Rank in traditional organic results | Search intent, topical authority, internal links, technical SEO, metadata |
| AEO | Appear in answer boxes and AI-generated summaries | Direct answers, concise summaries, clear structure, FAQ-style sections |
| GEO | Be referenced by generative engines | Entity clarity, original insight, proof, trust signals, source consistency |
| AI Search | Be selected as a source by ChatGPT, Bing/Copilot, Perplexity, Gemini-style systems | Crawlability, indexability, snippet eligibility, evidence, answer completeness |

The content must serve humans first, while being structured clearly enough for AI systems to parse, retrieve, summarize, and cite.

## 7. Answer-First Writing Rules

Every important section must start with the answer.

Rules:

- Start the page with a 40–70 word direct answer.
- Put the main answer in the first 100 words.
- Start each major section with a clear summary sentence.
- Use short, declarative sentences.
- Avoid long setup paragraphs.
- Avoid vague introductions.
- Do not make the reader wait for the answer.

Bad opening:

```text
In today's digital world, businesses need websites more than ever. There are many options available, and choosing the right agency can be difficult.
```

Better opening:

```text
[Brand] is a custom web design agency for businesses that need high-performance websites, advanced animations, and conversion-focused digital experiences. This page explains how our process works, who it is best for, what results to expect, and how to decide whether we are the right fit.
```

## 8. Formatting Rules for AI Extraction

Use formatting that makes the content easy to parse and cite.

Use:

- One H1
- Logical H2 and H3 structure
- Question-based headings
- Short paragraphs
- Bullet lists
- Numbered steps
- Tables
- Definitions
- Summary boxes
- FAQ sections
- Descriptive internal links

Avoid:

- Dense paragraphs
- Generic headings like “Overview” or “Benefits” without context
- Hidden content
- Important text inside images only
- Unsupported claims
- Keyword stuffing
- Repetitive phrasing
- Content that only restates what competitors already say

Include:

```text

```

Update the content when:

- Search intent changed

Schema rules:

- Schema must match visible page content.
- Do not add fake reviews.
- Do not add fake ratings.
- Do not add FAQ schema unless FAQs are visible on the page.
- Do not mark up claims that are not visible to users.
