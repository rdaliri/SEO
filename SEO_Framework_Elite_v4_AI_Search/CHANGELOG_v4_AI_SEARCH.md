## Main Strategic Change

Previous versions focused on SEO workflow control, local SEO, entity mapping, technical governance, and content production.

v4 adds a stronger AI-search layer. The new standard is:

```text
Do not optimize only to rank. Optimize to be selected, extracted, cited, and trusted.
```

## New Operating Rule

Every important content project must now include:

1. Search intent analysis
2. AI fan-out mapping
3. Entity mapping
4. Answer-first content structure
5. Evidence and proof review
6. Technical source eligibility check
7. AI visibility QA scorecard
8. Platform testing across Google, ChatGPT Search, Bing/Copilot, Perplexity, and Gemini where relevant
