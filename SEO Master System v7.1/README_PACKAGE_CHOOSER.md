## Selection Rules
- Select exactly one package for an active run.
- Never mix Full and Lite.
- Never mix Flat and Modular copies.
- Activate only one controller.
- Reference files are optional and non-authoritative.
- Archived and legacy controllers must not be loaded.
- Full is recommended for complex, client-facing, regulated, scaled, or high-risk work.
- Lite is recommended for routine, lower-risk production.
- Flat is recommended for manual ChatGPT loading.
- Modular is recommended for repositories, APIs, IDEs, agents, and automation.
