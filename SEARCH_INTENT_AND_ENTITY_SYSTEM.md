# Search Intent & Entity System

## Purpose
Improve semantic relevance and topical authority.

---

# Intent Classification

Every content request must classify intent before writing.

## Intent Types
- Informational
- Commercial
- Transactional
- Local
- Navigational
- Comparison
- Investigational
- Emergency

---

# Entity Mapping

Before writing:
- Identify primary entity
- Identify supporting entities
- Identify semantic relationships
- Identify topical gaps

---

# Semantic Coverage Rules

DO NOT optimize using keyword density targets.

INSTEAD optimize for:
- topical completeness
- semantic relevance
- contextual language
- search intent satisfaction

---

# Competitor Gap Analysis

Review:
- missing entities
- unanswered questions
- weak topic coverage
- missing subtopics

---

# Content Depth Strategy

Use:
- supporting concepts
- related terminology
- contextual explanations
- naturally connected ideas

Avoid:
- repetitive keyword stuffing
- unnatural exact-match repetition
