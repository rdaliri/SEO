# Reference Playbook: Context Handling v7

## Status
Reference-only. The canonical project context remains authoritative below the controller.

## Preserve
Market/language, audience, approved page purpose, intent, entity definitions, proof limits, claims restrictions, internal-link targets, CTA, technical constraints, and approved decisions.

## Compress
Resolved audit history, competitor observations, rejected variants, and prior drafts after decisions are recorded.

## Discard
Abandoned wording, duplicate brainstorms, failed titles, and obsolete temporary notes.

## Context Snapshot
- Project/task
- Mode: Full/Audit or Lite/Daily
- Market/language
- Audience and intent
- Page role
- Primary entities
- Approved proof and restricted claims
- Conversion goal
- Internal links
- Open assumptions and pending verification
- Next action

Do not change approved strategy silently. Record material changes in the decision log and canonical context.
